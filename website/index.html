FEATURES

Everything UPI.
None of the internet.

Auto Carrier Dialing

No dialer menus to navigate manually. OffPay leverages Android Accessibility APIs to drive NUUP network calls (*99#) automatically in the background. Experience real-time progress dialogs right inside the app.

$ offpay execute --ussd="*99#"
[OK] Established Connection to GSM Cell Tower (-68dBm)
[NUUP] NUUP Voice-Channel Response: 1. Send Money, 2. Check Balance...
$

Volatile RAM Buffers

Zero non-volatile residue. Your 4 or 6-digit UPI PIN is cleared from memory buffers within 500 milliseconds of submission. It is never saved, cached, or written to disk.

Zero Analytics

No telemetry, no tracking scripts, and no external servers. The app operates as an air-gapped sandbox. Your financial ledger belongs to you alone.

[OK] android.permission.CALL_PHONE - Configured

Pinch-to-Scan QR

Scan standard merchant codes without an active network. OffPay parses the UPI deep link URL locally, extracts the merchant identifier and pre-fills transaction screens instantly.

Keep a detailed record of your payments offline. Ledger entries are encrypted using industry-standard SQLCipher database formats on your device. Swipe to delete, tap to check details, or retry transfers with a single tap.

FAQ

Common questions,
straight answers.

Is OffPay a registered payment service or bank?
No. OffPay is an open-source Android interface that automates the dialing of *99#. All financial transactions are processed exclusively by NPCI through your carrier's NUUP infrastructure. OffPay never touches or routes your money.
Why doesn't it work on Jio?
Jio does not support the USSD-based *99# protocol. This is a carrier-level limitation from Reliance Jio's network architecture, not an OffPay bug. Jio's network doesn't route NUUP USSD calls. All other major Indian carriers (Airtel, Vi, BSNL) support it.
What happens to my UPI PIN?
OffPay uses Android's TelephonyManager.sendUssdRequest() API to forward your PIN directly to the carrier's USSD session. The PIN is held in a volatile memory buffer for <500ms and immediately zeroed. It is never logged, cached, or written to disk.
Do I need to create an account?
No account, no sign-up, no email, no phone verification. Install the APK and start paying. Your bank account is already linked to *99# by NPCI the moment you activated UPI — OffPay just provides a clean UI on top.
What is the transaction limit?
NPCI caps *99# transactions at ₹5,000 per transaction and ₹10,000 per day. These are network-level limits set by RBI/NPCI — not imposed by OffPay. Regular UPI apps have higher limits because they use data channels with stronger authentication flows.
Is the source code auditable?
Yes. OffPay is fully open source under the MIT License. The complete Android source code is available on GitHub at @laksh-ya/OffPayApp. You can verify every API call, permission, and data flow yourself before installing.
